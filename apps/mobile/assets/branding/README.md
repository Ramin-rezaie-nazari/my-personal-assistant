# Brand assets

This folder contains the canonical vector masters for product branding.

`mark.svg` is the mark-only asset.

`logo.svg` is the primary dark lockup with name, tagline, and descriptor.

`splash.svg` is the startup composition.

`icon.svg` is the square app-icon master.

The runtime mobile UI uses `BrandMark` and `BrandWordmark` so the visual identity stays consistent without introducing an image-loading dependency. The vector files are kept as source-of-truth assets for release packaging, web surfaces, marketing, and future native rasterization.
