# My Personal Assistant — Brand Guide

## Core identity
- Product name: My Personal Assistant
- Short name: Personal Assistant
- Tone: friendly, calm, capable, personal, modern
- Primary symbol: the brain/assistant mark

## Colors
- Primary: `#6D28D9`
- Primary dark: `#4C1D95`
- Accent: `#A78BFA`
- Background: `#F7F8FA`
- Surface: `#FFFFFF`
- Ink: `#111827`
- Muted: `#6B7280`
- Border: `#E5E7EB`
- Dark background: `#070B1A`
- Dark surface: `#111A39`
- Dark border: `#6D5CE7`

## UI rules
- Use the primary purple only for actions, selected states, highlights, and assistant identity.
- Keep large surfaces neutral so health, nutrition, fitness, and planning data remain the visual focus.
- Use rounded cards consistently; avoid mixing sharp and highly rounded components.
- Keep the assistant mark visually consistent across startup, navigation, assistant surfaces, and future notifications.
- Never use the logo as decoration when it competes with a primary task.
