# MYPA — C: Visual & Onboarding UX Roadmap

## Goal
Make the first-run experience feel polished, alive, personal, and visually consistent with the main MYPA product before adding more feature complexity.

## User feedback checklist

- [x] 1. Remove the green language-screen theme and align it with the MYPA violet visual system.
- [x] 2. Redesign the first onboarding screen so it is not a plain white/empty surface.
- [x] 3. Replace the vague first question with a clear question about the user's goal for nutrition and exercise.
- [x] 4. Center the MYPA wordmark/header instead of leaving it visually off-center.
- [x] 5. Fix Persian wording/word order, including the MYPA personalization wording.
- [x] 6. Make the first goal option "کاهش چربی و کاهش وزن".
- [x] 7. Keep "خوش‌فرم شدن" as a combined nutrition + exercise goal, not an exercise-only concept.
- [x] 8. Make the third goal "عضله‌سازی و قدرت بیشتر" so both muscle gain and strength are represented.
- [x] 9. Replace the overly dark/black-feeling app mark with the brighter violet MYPA mark.

## Responsive UX

- [x] Keep onboarding content scrollable on short/small Android screens.
- [x] Keep primary actions reachable without clipping.
- [x] Keep the visual hierarchy stable across all five onboarding steps.

## Visual direction

- Primary accent: MYPA violet / purple.
- Background: soft neutral canvas with subtle depth.
- Cards: white/elevated surfaces with restrained borders and shadows.
- Logo: bright, friendly, memorable; avoid a heavy black-first appearance.
- Persian UI: natural word order, comfortable RTL spacing, no mixed-direction awkwardness.
- First impression target: the user should feel that the app is alive and thoughtfully designed within the first few seconds.

## Next pass after this checkpoint

Review the five onboarding screens on the physical Android device and tune spacing, typography, option-card density, and animation based on the real screen rather than assumptions.
